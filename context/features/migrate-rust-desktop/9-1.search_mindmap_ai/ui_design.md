# 搜索、思维导图和 AI 迁移 — UI 设计

## 搜索体验

Desktop 搜索入口复用现有搜索框。若后续加入桌面快捷键，`Ctrl + Shift + K` 可聚焦搜索框或打开快速搜索面板。

搜索结果展示保持与 Web 端一致：

1. 关键词输入框。
2. 分类、标签、系统筛选。
3. 收藏、置顶筛选。
4. 结果列表和空状态。

## 思维导图体验

思维导图视图复用现有画布和编辑交互。保存中显示 loading，保存失败保留当前编辑内容并提示可重试。

## AI 体验

AI 按钮保留在已有编辑或详情区域：

| 动作 | UI |
| ---- | -- |
| 摘要 | 生成摘要按钮 |
| 自动标签 | 标签区域的建议按钮 |
| Prompt 优化 | Prompt 编辑区操作按钮 |

AI Key 未配置时，引导用户到设置页 AI 面板配置，不在当前弹窗中要求输入密钥。
