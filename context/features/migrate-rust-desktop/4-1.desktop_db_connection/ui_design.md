# Desktop 数据库连接 — UI 设计

## 设置页入口

Desktop 运行时，设置页显示「数据库」面板；Web 运行时隐藏该面板。

设置结构：

```txt
设置
├── 通用
├── 主题
├── AI
└── 数据库（仅 Desktop）
```

## 数据库面板

字段布局建议为紧凑表单：

| 控件 | 类型 |
| ---- | ---- |
| 主机 | 文本输入 |
| 端口 | 数字输入，默认 5432 |
| 数据库名 | 文本输入 |
| 用户名 | 文本输入 |
| 密码 | 密码输入 |
| SSL 模式 | 下拉菜单 |

按钮：

| 按钮 | 行为 |
| ---- | ---- |
| 测试连接 | 调用 `testDatabaseConnection` |
| 保存 | 保存配置并刷新连接池 |

## 状态呈现

| 状态 | UI |
| ---- | -- |
| 未配置 | 显示待配置提示和空表单 |
| 测试中 | 测试按钮 loading，表单保持可见 |
| 测试成功 | 显示成功提示 |
| 测试失败 | 在表单下方显示错误消息 |
| 已保存 | 显示保存成功提示 |

错误提示应说明用户可以采取的动作，例如检查主机、端口、账号、密码或网络连接。
