# Tauri 桌面壳 — UI 设计

## 窗口设计

Desktop 首屏沿用现有 Web UI，不新增独立启动页。

窗口建议：

| 属性 | 值 |
| ---- | -- |
| 标题 | `Personal Knowledge Desktop` |
| 默认宽度 | `1280` |
| 默认高度 | `800` |
| 最小宽度 | `1024` |
| 最小高度 | `700` |
| 是否可缩放 | 是 |

## 视觉原则

1. 桌面窗口中的内容布局应与 Web 端保持一致。
2. 不在该阶段新增营销式欢迎页。
3. 如果当前 Web UI 已有侧边栏、列表、详情区，Desktop 直接复用。
4. 避免在窗口顶部重复渲染浏览器式导航。

## 初始状态

Desktop 打开后进入现有默认页面。若当前页面因为后端能力未迁移而请求失败，应显示现有错误状态或空状态，不新增复杂引导。
