# Windows 打包发布 — UI 设计

## 首次启动

首次启动如果没有数据库配置，应用进入可操作的设置状态，而不是空白页面。

建议展示：

1. 当前未配置数据库。
2. 数据库配置表单入口。
3. 测试连接和保存按钮。

## 应用标识

Windows 中展示统一名称：

```txt
Personal Knowledge Desktop
```

图标用于：

1. 应用窗口。
2. 任务栏。
3. 开始菜单。
4. 安装包。
5. 卸载列表。

## 安装体验

安装器使用标准 Windows 安装流程即可，不需要额外宣传页。安装完成后可选择立即启动应用。

## 卸载体验

卸载不需要应用内 UI。若未来支持清理本地配置，需要在安装器或设置页明确说明会删除哪些数据。
