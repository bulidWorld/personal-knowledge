# Desktop 原生能力增强

## 业务目标

在基础 Desktop 功能可用后，补充桌面原生体验，包括菜单栏、系统托盘、全局快捷键、拖拽上传、剪贴板快速保存、最近打开知识、启动检查和离线提示。

该阶段让 Desktop 不只是网页套壳，而是更贴近 Windows 桌面应用。

## 使用场景

### 快捷键快速搜索

用户在应用内或全局按下 `Ctrl + Shift + K`，快速打开搜索或聚焦搜索框。

### 托盘常驻

用户关闭主窗口时，应用可以最小化到系统托盘；用户从托盘菜单重新打开窗口或退出应用。

### 拖拽文件上传

用户把文件拖到知识详情或编辑区域，系统上传并关联到当前知识条目。

### 剪贴板快速保存

用户通过快捷键将剪贴板文本保存为新知识或进入快速创建弹窗。

## 功能范围

1. 应用菜单栏。
2. 系统托盘。
3. 全局快捷键。
4. 拖拽文件上传。
5. 剪贴板快速保存。
6. 最近打开知识。
7. 启动时检查数据库连接。
8. 离线状态提示。
9. 临时文件清理。

## 推荐快捷键

| 快捷键 | 行为 |
| ------ | ---- |
| `Ctrl + Shift + K` | 快速搜索 |
| `Ctrl + N` | 新建知识 |
| `Ctrl + Shift + V` | 保存剪贴板 |
| `Ctrl + ,` | 打开设置 |

## 验收标准

1. 菜单栏可用。
2. 托盘可用。
3. 快捷键可用。
4. 拖拽上传可用。
5. 数据库断开时提示清楚。
6. 临时文件清理不会误删用户文件。
