# Desktop 原生能力增强 — UI 设计

## 快速搜索

快速搜索可以复用现有搜索框，或使用轻量命令面板。

面板包含：

1. 搜索输入。
2. 最近打开知识。
3. 匹配结果列表。
4. 键盘上下选择和回车打开。

## 托盘体验

当用户点击窗口关闭按钮：

1. 如果配置为最小化到托盘，窗口隐藏并显示一次提示。
2. 托盘菜单提供重新打开和退出。
3. 如果用户选择退出，则真正结束应用。

## 拖拽上传

知识详情或编辑区域在拖入文件时显示轻量覆盖态：

```txt
释放以上传附件
```

释放后进入上传状态，成功后文件列表更新。

## 离线提示

数据库断开时，顶部显示横幅：

```txt
无法连接数据库。请检查网络或数据库设置。
```

横幅提供「重试」和「打开设置」两个操作。

## 最近打开

快速搜索或侧边区域可以展示最近打开知识。每一项显示标题、更新时间和所属分类。
