# Desktop 文件模块 — UI 设计

## 文件选择

文件上传控件复用现有附件入口。Desktop 下点击上传时打开系统文件选择器；Web 下仍然使用浏览器 `<input type="file">`。

按钮文案保持一致，例如「上传附件」，不要让用户感知底层实现差异。

## 文件列表

文件列表展示：

| 信息 | 说明 |
| ---- | ---- |
| 文件名 | 原始文件名 |
| 类型 | MIME 或扩展名 |
| 大小 | 格式化为 KB / MB |
| 上传时间 | 使用当前项目已有日期格式 |
| 操作 | 打开、导出、取消关联、删除 |

操作建议使用图标按钮，并提供 hover tooltip。

## 上传状态

| 状态 | UI |
| ---- | -- |
| 选择中 | 保持当前界面 |
| 上传中 | 显示进度或 loading |
| 成功 | 文件列表新增记录 |
| 文件过大 | 显示明确错误 |
| 上传失败 | 显示可重试错误 |

## 打开与导出

Desktop 中：

1. 「打开」调用系统默认程序，不在应用内强行预览所有文件。
2. 「导出」打开系统保存对话框。
3. 临时文件打开失败时提示用户检查默认程序或文件权限。

Web 中：

1. 「打开」使用浏览器预览或下载。
2. 「导出」使用浏览器下载能力。
