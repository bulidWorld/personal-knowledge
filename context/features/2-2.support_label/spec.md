# 支持标签功能

## 业务描述

为所有知识条目提供标签（Tag）功能，允许用户通过多对多的方式对条目进行分类标记，并通过标签快速筛选内容。与分类（Category）的单选不同，一个条目可以同时拥有多个标签。

## 默认标签

系统预置 5 个标签，安装后即可使用：

| 名称 | 颜色 | 含义 |
|------|------|------|
| 设计 | indigo #6366f1 | 设计相关的知识、架构图、原型稿 |
| 开发 | emerald #10b981 | 开发实现、代码片段、技术文档 |
| 测试 | amber #f59e0b | 测试用例、测试报告、QA 相关 |
| 运维 | sky #0ea5e9 | 部署脚本、运维手册、配置管理 |
| 调试 | rose #f43f5e | 调试技巧、问题排查、日志分析 |

## 使用方式

### 为条目打标签

1. **新建条目时** — 在创建表单中，分类选择器下方会显示所有可用标签，点击即可选中/取消，选中的标签高亮显示为标签颜色
2. **编辑条目时** — 在编辑表单（弹窗模式或详情页内联编辑模式）中同样可以添加/移除标签
3. 每个条目可以同时拥有任意数量的标签

### 按标签筛选

1. 在左侧边栏 "标签" 区域，点击某个标签即可筛选出包含该标签的所有条目
2. 再次点击已选中的标签，取消筛选，恢复显示全部条目
3. 页面顶部会显示当前激活的标签过滤条件，可点击 ✕ 快速清除

### 管理标签

1. **新建标签** — 点击侧边栏 "标签" 区域右侧的 + 按钮，输入名称并选择颜色
2. **编辑标签** — 鼠标悬停在标签上，点击出现的铅笔图标，可修改名称或颜色
3. **删除标签** — 鼠标悬停在标签上，点击出现的垃圾桶图标，确认后删除（关联关系自动清理）

## 标签 vs 分类

| | 标签 | 分类 |
|---|---|---|
| 关系 | 多对多（一个条目可有多个标签） | 一对一（一个条目只属于一个分类） |
| 来源 | 用户自定义 + 系统预置 | 用户自定义 |
| 用途 | 跨维度标记（如同时标记"开发"+"调试"） | 归属分类（如"React Patterns"） |
